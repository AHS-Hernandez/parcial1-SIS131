# parcial1-SIS131

Simulador de CPU von Neumann/x86 de **8 bits** en Microsoft Excel + VBA (`.xlsm`), para el Parcial 1 de Arquitectura de Computadoras (SIS131).

**Repositorio:** https://github.com/AHS-Hernandez/parcial1-SIS131  
**Responsable:** AHS-Hernandez (adriana.hernandez@ucb.edu.bo)  
**Periodo de trabajo:** 24/09/2026 – 26/09/2026

## Estructura

| Ruta | Contenido |
|---|---|
| `SimuladorCPU.xlsm` | Libro con macros (raíz del repositorio) |
| `docs/` | Análisis, arquitectura y defensa |
| `src/` | Código VBA exportado como texto |

El `.xlsm` vive en la raíz. `src/` guarda los módulos exportados para versionarlos; mientras no haya exportación, la carpeta se mantiene con `.gitkeep`.
